DEVELOOP STUDIOS — SEO WEBSITE PACKAGE
======================================

FILES
- index.html: responsive single-page website with SEO metadata and JSON-LD structured data
- robots.txt: crawl instructions and sitemap location
- sitemap.xml: initial sitemap for the homepage
- SEO-DEPLOYMENT-GUIDE.txt: deployment and Google Search Console checklist

IMPORTANT BEFORE UPLOADING
1. Choose and purchase your domain.
2. In index.html, replace every instance of https://YOUR-DOMAIN.com with your final canonical HTTPS domain (without changing the path structure).
3. In robots.txt and sitemap.xml, replace YOUR-DOMAIN.com with the same real domain.
4. Create /assets/develoop-studios-social.jpg (recommended 1200x630) for social sharing, or update/remove the og:image and twitter:image tags until that image exists.
5. Confirm the displayed phone numbers are correct.
6. Confirm the experience statement and contact details are accurate.
7. Add a favicon.ico file or remove its link if you do not have one.

HOSTING
Upload index.html, robots.txt, and sitemap.xml to the public web root (often public_html). The URLs should become:
https://YOUR-DOMAIN.com/
https://YOUR-DOMAIN.com/robots.txt
https://YOUR-DOMAIN.com/sitemap.xml

SEARCH CONSOLE
See SEO-DEPLOYMENT-GUIDE.txt. Indexing is not guaranteed; Google makes its own crawl and indexing decisions.

NOTES
- The site uses no external JavaScript libraries or paid plugins.
- JSON-LD describes an independent service provider. It does not imply affiliation with Google.
- The D-U-N-S content is phrased as lookup/application guidance, not a promise to sell or issue identifiers.
- The current sitemap includes only the homepage because this package is a single-page website.
